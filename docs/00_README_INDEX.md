# MY_LMS — индекс документации

> Рабочее название проекта: **MY_LMS**. Финальное имя, логотип и тексты брендинга задаются в `07_design.md`.

## 1. Что это
Telegram-бот и связанный с ним веб-интерфейс (Mini App внутри Telegram, он же сайт в обычном браузере) для частного преподавателя. Автоматизирует расписание, домашние задания, пробные экзамены, учёт заработка и уведомления.

## 4. Принятые ключевые решения (кратко)
- **Бэкенд:** Python 3.11, FastAPI, Aiogram 3, SQLAlchemy 2 (async), PostgreSQL, Redis, TaskIQ. Менеджер пакетов: uv.
- **Фронтенд:** TypeScript (strict), React, Vite, React Router, TanStack Query, Tailwind CSS, shadcn/ui, Recharts. Менеджер пакетов: pnpm.
- **Контракт:** REST `/api/v1`; из OpenAPI-схемы бэкенда автоматически генерируются TypeScript-типы.
- Бот и API работают в одном процессе и вызывают одни и те же `services/`. Фронтенд — отдельное SPA, раздаётся Nginx с того же домена.
- Сессии серверные (Redis), cookie `HttpOnly`. Паролей нет.
- Вход **только по одноразовой ссылке-приглашению**. Один аккаунт = один `telegram_id`.
- Финансы видит только `owner`, только для расчёта заработка. Платежей, баланса занятий и должников нет.
- Роли: `owner`, `manager`, `student`. «Гость» — состояние без аккаунта.
- Экзамены: информатика ОГЭ, информатика ЕГЭ, математика ОГЭ, математика ЕГЭ (профиль).
- Хостинг и данные в РФ.

## 5. Глоссарий

| Термин | Значение |
|---|---|
| Гость | Пользователь бота без привязанного аккаунта |
| Ученик (student) | Пользователь, которого создал персонал и который принял приглашение |
| Владелец (owner) | Преподаватель, полный доступ включая финансы |
| Менеджер (manager) | Сотрудник: ученики, расписание, ДЗ, каталог; без финансов |
| Персонал (staff) | owner или manager |
| Приглашение | Одноразовая ссылка `t.me/<bot>?start=inv_<token>` для привязки Telegram к аккаунту |
| Урок (lesson) | Занятие с одним или несколькими участниками |
| Шаблон расписания | Правило «каждый вторник в 17:00», из которого генерируются уроки |
| Задание (homework) | Описание ДЗ, общее для всех, кому оно выдано |
| Выдача (assignment) | Конкретное ДЗ конкретного ученика: статус, оценка, дедлайн |
| Первичный балл | Сырой балл экзамена |
| Тестовый балл | 100-балльный результат ЕГЭ |
| Пробник | Пробный экзамен (ОГЭ/ЕГЭ) |
| Перенос дедлайна | Сдвиг дедлайна ДЗ на следующее занятие; максимум 2 раза на выдачу |
| Снимок цены | Цена урока, зафиксированная в момент проведения |
| SPA | Одностраничное приложение: страницы переключаются без перезагрузки |
| OpenAPI | Машиночитаемое описание REST API, из которого генерируются TypeScript-типы |
