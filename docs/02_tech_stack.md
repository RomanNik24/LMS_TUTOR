# 02. Технологический стек и инфраструктура

Стек зафиксирован. Заменять библиотеки без согласования с владельцем проекта нельзя. Точные версии фиксируются в `uv.lock` (бэкенд) и `pnpm-lock.yaml` (фронтенд). При старте проекта берутся актуальные стабильные версии, совместимые друг с другом.

## 1. Общая картина
Проект состоит из двух частей, которые общаются по HTTP:

| Часть | Язык | Что делает |
|---|---|---|
| **Бэкенд** (`src/`) | Python 3.11 | Бизнес-логика, БД, REST API, Telegram-бот, фоновые задачи |
| **Фронтенд** (`frontend/`) | TypeScript | Веб-интерфейс (Mini App внутри Telegram и сайт в браузере) |

Контракт между ними: **OpenAPI-схема**, которую FastAPI генерирует автоматически. Из неё автоматически создаются TypeScript-типы, поэтому фронтенд и бэкенд не расходятся.

## 2. Бэкенд

### 2.1. Язык и инструменты
| Компонент | Выбор | Почему |
|---|---|---|
| Язык | **Python 3.11** | Уже установлен у владельца |
| Пакетный менеджер | **uv** (`pyproject.toml` + `uv.lock`) | Быстрый, воспроизводимые сборки |
| Типизация | Type hints, **MyPy strict** | Меньше ошибок |
| Линтер/форматер | **Ruff** | Один инструмент |

### 2.2. Приложение
| Компонент | Выбор | Назначение |
|---|---|---|
| Бот | **Aiogram 3.x** | Webhook на проде, polling локально (`BOT_MODE`) |
| API | **FastAPI + Uvicorn** | REST `/api/v1`, вебхук бота, `/health`, автогенерация OpenAPI |
| Валидация/DTO | **Pydantic v2** (+ `pydantic-settings`) | Схемы запросов/ответов, конфигурация |
| Сессии | **Серверные сессии в Redis**, идентификатор в cookie (`HttpOnly`, `Secure`, `SameSite=Lax`) | Можно мгновенно отозвать, нет токенов в JavaScript |

Бот и API работают в **одном процессе** и вызывают одни и те же `services/` напрямую.

### 2.3. Данные
| Компонент | Выбор | Назначение |
|---|---|---|
| СУБД | **PostgreSQL 16+** | Основная БД |
| ORM | **SQLAlchemy 2.0** (async-синтаксис) | Модели и запросы |
| Драйвер | **asyncpg** | Async-доступ |
| Миграции | **Alembic** | Версии схемы |
| Redis | **Redis 7** | FSM бота, сессии, брокер TaskIQ, rate limiting |
| Файлы | **S3-совместимое хранилище в РФ** (Timeweb Cloud S3 или Selectel S3) | Фото и файлы ДЗ |
| S3-клиент | **aioboto3** | Async-загрузка, presigned URL |
| Обработка фото | **Pillow** + `pillow-heif` | Сжатие, HEIC → JPEG |

Расширения PostgreSQL: `btree_gist` (запрет пересечения уроков).

### 2.4. Фоновые задачи
**TaskIQ** + `taskiq-redis`, планировщик TaskIQ (cron). Подход: проверка раз в минуту выбирает из БД «что пора отправить» и пишет в таблицу `notifications` с уникальным `dedup_key` (подробнее `03`, `05`).

### 2.5. Безопасность
| Компонент | Выбор |
|---|---|
| Токены приглашений/входа | `secrets.token_urlsafe(32)`, в БД только SHA-256 хэш |
| Валидация Telegram `initData` | HMAC-SHA256 (алгоритм Telegram WebApp) |
| Rate limiting | Redis-счётчики (`slowapi` или собственная зависимость FastAPI) |
| CSRF | `SameSite=Lax` + проверка заголовков `Origin` и `X-Requested-With` на изменяющих запросах |
| Пароли | Не используются (`argon2-cffi` подключается, только если пароли когда-либо появятся) |

## 3. Фронтенд

### 3.1. Основа
| Компонент | Выбор | Зачем |
|---|---|---|
| Язык | **TypeScript** (режим `strict`) | Типы ловят ошибки до запуска |
| Библиотека UI | **React 18+** | Самая популярная, огромная экосистема |
| Сборщик/dev-сервер | **Vite** | Быстрый старт и сборка |
| Пакетный менеджер | **pnpm** | Быстрый, экономит место, строгий |
| Роутинг | **React Router** | Страницы и навигация |
| Запросы и кеш | **TanStack Query** | Загрузка данных, кеш, повторы, состояние загрузки/ошибки |
| API-клиент | **openapi-fetch** + типы от **openapi-typescript** | Типобезопасные запросы, типы генерируются из OpenAPI бэкенда |
| Формы | **react-hook-form** + **Zod** (`@hookform/resolvers`) | Формы и валидация |
| Стили | **Tailwind CSS** | Стили классами, быстрая адаптивность, токены дизайна |
| Компоненты | **shadcn/ui** (на Radix UI) | Готовые доступные компоненты, код лежит в проекте и свободно правится |
| Иконки | **lucide-react** | |
| Графики | **Recharts** | Линейные графики и столбцы |
| Даты и время | **date-fns** (+ `@date-fns/tz`) | Часовые пояса, форматирование |
| Уведомления в UI | **sonner** (тосты) | |
| Интеграция с Telegram | **@telegram-apps/sdk-react** | Тема, `initData`, кнопки Telegram, safe area |

Состояние: данные с сервера — только **TanStack Query**; локальное состояние — `useState`/`useReducer`. Глобальные хранилища (Redux, Zustand) **не используются**.

### 3.2. Качество фронтенда
| Компонент | Выбор |
|---|---|
| Линтер | **ESLint** (typescript-eslint, react-hooks) |
| Форматер | **Prettier** |
| Юнит и компонентные тесты | **Vitest** + **Testing Library** |
| Моки API в тестах | **MSW** |
| Сквозные тесты | **Playwright** (после MVP-ядра) |
| Проверка типов | `tsc --noEmit` |

### 3.3. Что НЕ используем (и почему)
- **Next.js:** серверный рендеринг для Mini App не нужен, усложняет деплой.
- **Redux/Zustand:** хватает TanStack Query и локального состояния.
- **CSS-in-JS, Bootstrap, Material UI:** конфликтуют с подходом Tailwind + shadcn.
- **GraphQL:** избыточно.
- **JavaScript без типов:** только TypeScript.

## 4. Общие инструменты разработки
| Компонент | Выбор |
|---|---|
| Бэкенд-тесты | `pytest`, `pytest-asyncio`, `testcontainers`, `pytest-cov`, `time-machine` |
| Pre-commit | `ruff`, `mypy`, ESLint/Prettier для фронта, проверка секретов |
| Ошибки | **Sentry** (бэкенд и фронтенд; без персональных данных) |
| Логи | JSON в stdout, без персональных данных |
| Healthcheck | `GET /health` + внешний uptime-мониторинг |

Метрики Prometheus/Grafana не используются.

## 5. Инфраструктура
| Компонент | Выбор |
|---|---|
| Контейнеры | Docker + Docker Compose |
| Reverse proxy | **Nginx**: раздаёт статику фронтенда, проксирует `/api` и `/telegram` на бэкенд, SSL |
| Хостинг | VPS **в РФ** (Timeweb Cloud или Selectel), Ubuntu LTS, 2 vCPU / 4 ГБ RAM |
| CI/CD | GitHub Actions: lint → тесты бэкенда и фронта → сборка → деплой по SSH |
| Окружения | `local`, `staging` (отдельный бот), `prod` |
| Бэкапы | Ежедневный `pg_dump` в S3, 14 дней |

### Контейнеры
`app` (FastAPI + Aiogram webhook), `worker`, `scheduler`, `postgres`, `redis`, `nginx` (внутри собранный фронтенд `frontend/dist`). Локально S3 эмулируется MinIO, а фронтенд запускается отдельно через `pnpm dev`.

## 6. Доступ к Telegram из РФ
- `TELEGRAM_API_BASE`, `TELEGRAM_PROXY_URL` (необязательно) для исходящих запросов бота.
- Все исходящие обращения к Telegram идут через единый модуль `bot/client.py`.
- Отправка уведомлений идёт через интерфейс `Notifier` (задел под MAX).
- Веб-интерфейс работает и в обычном браузере по одноразовой ссылке входа.

## 7. Конфигурация
- Бэкенд: `pydantic-settings`, шаблон `.env.example`.
- Фронтенд: переменные `VITE_*` (только публичные значения: имя бота, адрес API). Секретов во фронтенде **нет и быть не может**.
- Основные переменные бэкенда: `APP_ENV`, `DATABASE_URL`, `REDIS_URL`, `BOT_TOKEN`, `BOT_MODE`, `WEBHOOK_URL`, `WEBHOOK_SECRET`, `OWNER_TELEGRAM_ID`, `TEACHER_CONTACT_URL`, `PUBLIC_BASE_URL`, `SESSION_SECRET`, `S3_*`, `SENTRY_DSN`, `SCHEDULE_HORIZON_WEEKS`, `DEFAULT_TIMEZONE`, `TELEGRAM_API_BASE`, `TELEGRAM_PROXY_URL`.
- Фронтенд: `VITE_API_BASE_URL` (по умолчанию `/api/v1`), `VITE_BOT_USERNAME`, `VITE_SENTRY_DSN`.
