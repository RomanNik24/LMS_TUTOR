## 1. Принципы бренда в интерфейсе
- **Голос:** молодой репетитор-практик, «старший брат, который прошёл этот путь». Прямо, без воды, цифры и факты вместо оценочных слов.
- **Энергия слайдов, чистота интерфейса:** бренд дерзкий в обложках, но приложение — рабочий инструмент. Яркий зелёный и амбер используются точечно, остальное — спокойные нейтральные тона.
- **Ритм «цветное / светлое»** (из брендбука): насыщенно-зелёные блоки (шапки, главные карточки) чередуются со светло-серым фоном и белыми карточками.
- **Один акцент.** На экране не более одного амбер-элемента (см. 3.2).
- **Единый средний радиус** скругления по всему приложению (см. 5).
- **Только line-art иконки**, плоские, без 3D и заливки.

### Решения по расхождениям в брендбуке
| Расхождение | Решение |
|---|---|
| Светло-зелёный в Визуальном гайде записан с опечаткой (`#4FD business 484`) | Берём `#6FE39C` (указан в том же гайде в пояснении и в Brand-guide) |
| Шрифт лого: Визуальный гайд — Unbounded или Montserrat Black; Brand-guide — Montserrat 700–900 | ⚠ Лого в интерфейсе набираем **Montserrat 900** (как в финальном коде слайдов). Если появится нарисованный лого-файл, он заменяет текстовый набор |
| Brand-guide: «белый на зелёном — AA+» | На деле белый на `#1FAA59` ≈ **3,0 : 1**, что подходит только для крупного жирного текста. Правила для интерфейса — в 3.3 |

### 2.1. Логотип в интерфейсе
- Текстовый набор: «Ромчик» + тонкий разделитель `|` + «ИнфоМат». Montserrat 900, заглавными.
- На светлом фоне: «РОМЧИК» — `#141414`, «ИНФОМАТ» — `#137A3E`.
- На зелёном и тёмном фоне: «РОМЧИК» — `#FFFFFF`, «ИНФОМАТ» — `#6FE39C` (на тёмном фоне) либо `#FFFFFF` (на насыщенно-зелёном).
- Разделитель `|` тоньше основных букв (вес 300), цвет `--gray-500`.
- Минимальная высота лого в шапке: 20 px. Охранное поле: не менее высоты буквы «Р» со всех сторон.
- Лого не накладывается на лицо и текст, не растягивается, не отдаётся в амбере.

### 2.2. Фотографии
- Один и тот же портрет (одна цветокоррекция) во всех местах. Ретушь минимальная; допускаются `saturate` и `contrast` не выше 1.05.
- Кадрирование через переменные (если нужен сдвиг): `--photo-img-y`, `--photo-img-zoom`. Лицо в верхней трети.
- Фон на фото нейтральный/однотонный, без конкурирующих цветов.

### 3.2. Правила использования
1. **Один амбер-акцент на экран (на видимую область).** Допустим либо ключевая цифра/чип результата, либо главная кнопка действия, но не оба сразу. Амбер занимает не более 10–15% площади.
2. **Зелёный** — основной цвет интерфейса: шапки-герои, активные элементы, графики, иконки.
3. ⚠ **Красный** (`--red`) — только сигнал: ошибки, «Просрочено», «Не пришёл», опасные действия. Это единственное исключение из палитры; других красных, синих и фиолетовых оттенков не использовать.
4. ⚠ **Сигнальные подложки** (`--amber-tint`, `--red-tint`, `--green-tint`) в статус-бейджах считаются низкоакцентными и **не нарушают** правило одного амбера, поскольку не являются главным фокусом.
5. В **списках** одинаковых карточек (уроки, ДЗ) амбер **не повторяется**: результаты в списке — зелёные. Амбер-чип результата допустим на детальном экране или как «последний результат» на отчёте.
6. Цвет никогда не единственный носитель смысла: статус = цвет + текст (или иконка).
7. Не использовать холодные синие/фиолетовые как основные.

### 3.3. Контраст и допустимые пары (⚠ правила для интерфейса)
Значения рассчитаны приблизительно; перед релизом проверить инструментом контраста.

| Пара | Контраст | Использовать |
|---|---|---|
| Белый на `#137A3E` | ≈ 5,4 : 1 | **Основные кнопки**, любой размер текста |
| Белый на `#1FAA59` | ≈ 3,0 : 1 | Только крупный жирный текст (≥ 20 px, вес ≥ 700), иконки, декоративные поверхности (шапки-герои) |
| `#141414` на `#1FAA59` | ≈ 6 : 1 | Мелкий текст на ярко-зелёной поверхности |
| `#141414` на `#FF9B2E` | ≈ 8,7 : 1 | **Текст на амбере всегда тёмный** |
| `#FF9B2E` / `#E67E00` на белом | ≈ 2,1 / 2,9 : 1 | **Нельзя** для мелкого текста. Амбер — только как заливка или обводка/крупная цифра ≥ 24 px |
| `#137A3E` на белом | ≈ 5,4 : 1 | Зелёный текст и ссылки на светлом |

### 3.5. Темы
- ⚠ **Светлая тема — основная** (так построен брендбук). Тёмная — производная для комфорта в Telegram.
- Режим определяется темой Telegram (`colorScheme`) в Mini App, в браузере — `prefers-color-scheme`. Пользовательского переключателя в MVP нет.
- Бренд-акценты **не берутся** из темы Telegram: фон, текст и акценты — только наши токены.
- Шапка и нижняя панель Telegram окрашиваются в `--background` (светлая: `#F2F2F2`, тёмная: `#141414`) для цельного вида.

## 4. Типографика

### 4.1. Шрифты
| Роль | Шрифт | Где |
|---|---|---|
| Display / заголовки H1 / ключевые цифры | **Unbounded** 700–800 | Название экрана, большие числа, нумерация шагов «01», результат «11/13» |
| Подзаголовки, кнопки, бейджи, лого | **Montserrat** 700–900 | H2/H3, подписи кнопок, статус-бейджи, логотип |
| Основной текст и подписи | **Inter** 400–600 | Всё остальное |

- Не более двух семейств в одном блоке: Unbounded с Inter либо Montserrat с Inter.
- ⚠ **Самохостинг:** шрифты ставятся npm-пакетами `@fontsource-variable/unbounded`, `@fontsource-variable/montserrat`, `@fontsource-variable/inter` (подключаются только подмножества `cyrillic` и `latin`). Внешние источники, включая Google Fonts, **не используются**: из РФ они могут быть недоступны. Все три шрифта распространяются по свободной лицензии (OFL).
- Запасной стек: `system-ui, -apple-system, "Segoe UI", sans-serif`. Для Unbounded запасной — Montserrat (по брендбуку).

### 4.2. Шкала (⚠ адаптация размеров слайдов под интерфейс)
| Стиль | Шрифт и вес | Моб. / десктоп (px) | Трекинг | Регистр |
|---|---|---|---|---|
| Display (цифра, герой) | Unbounded 800 | 36/40 → 48/52 | −0.02em | как есть |
| H1 (название экрана) | Unbounded 800 | 22/28 → 28/34 | −0.02em | **ЗАГЛАВНЫЕ** |
| H2 | Montserrat 700 | 18/24 → 20/28 | −0.01em | обычный |
| H3 | Montserrat 700 | 16/22 | 0 | обычный |
| Основной текст | Inter 400/500 | 16/24 | 0 | обычный |
| Вторичный текст | Inter 400 | 14/20 | 0 | обычный |
| Подпись | Inter 400/500 | 12/16 | 0 | обычный |
| Кнопка | Montserrat 800 | 14/16 | +0.02em | **ЗАГЛАВНЫЕ**, до 3 слов; длиннее → обычный регистр |
| Бейдж/статус | Montserrat 800 | 11/14 | +0.03em | **ЗАГЛАВНЫЕ** |
| Нумерация шагов («01») | Unbounded 700 | 24/28 | −0.02em | цвет — зелёный (`--primary`) |

Правила:
- Заголовки экрана — заглавными (как в брендбуке), но **длинный текст заглавными не набираем**: всё, что длиннее ~4 слов, — обычный регистр.
- Основной текст — обычный регистр и вес 400–500, не жирный.
- Поля ввода — шрифт не менее 16 px (иначе iOS приближает страницу).
- Заголовок H1 — не более 2 строк; кегль H1 не ниже 20 px (Unbounded — широкий шрифт).
- Цифры в таблицах и отчётах: `font-variant-numeric: tabular-nums`.

## 5. Сетка, отступы, скругления, тени
- **Шкала отступов (база 4 px):** 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48.
- **Поля страницы:** моб. 16 px, планшет 24 px, десктоп 32 px. Зазор между карточками 12 px (моб.) / 16 px (десктоп).
- **Брейкпоинты:** мобильный 360–767, планшет 768–1023, десктоп ≥ 1024 (Tailwind: `md`, `lg`).
- **Ширина контента:** Student App на десктопе — центрированная колонка до 560 px. Admin App — до 1280 px, боковое меню 240 px.
- **Радиусы:** ⚠ единый средний радиус по бренду: `--radius` = 12 px (кнопки, поля, карточки, чекбоксы 6 px), `--radius-lg` = 16 px (крупные карточки, листы-шторки), `--radius-sm` = 8 px (бейджи, мелкие чипы). Полностью круглыми (pill) делаются только аватары и точки-маркеры. Острых углов (0) нет.
- **Тени:** мягкие `--shadow-card`; всплывающие слои `--shadow-overlay`. Только `box-shadow`.
- **Размытие фона (`backdrop-filter`)** и «стеклянные» плашки из слайдов в интерфейсе **не используются** (нагрузка на WebView). Исключение: статичные декоративные элементы в шапке-герое.
- **Размеры нажимаемых элементов:** не менее 44×44 px; основная кнопка 48 px, поле ввода 48 px.
- **Безопасные зоны:** отступы под вырезы экрана через `env(safe-area-inset-*)`; высота экрана `100dvh`.

### 5.1. Декоративные приёмы (из слайдов, только на герой-блоках)
- **Диагональный срез**: нижняя граница шапки-героя срезана диагональю (clip-path), как «срезы» из визуального гайда. Применяется на главных экранах (расписание ученика, дашборд).
- **Свечение/блики**: мягкие светлые пятна на герое с прозрачностью 3–5%.
- **Микро-чёрточка** под заголовком героя: короткая скошенная линия `--brand-green-light`, одинаковой позиции на всех экранах.
- **Наклон** `-1°…-2°` допустим только у декоративных элементов (пустые состояния, герой), **не у интерактивных**.

Общее: берём готовые компоненты shadcn/ui и настраиваем токенами. Новые формы «для разнообразия» не изобретаем.

### 6.1. Кнопки
| Вариант | Вид | Применение |

### 6.2. Поля ввода
Высота 48, радиус 12, граница `--input`, фон `--card`; при фокусе граница `--primary` + кольцо `--ring`; ошибка: граница `--destructive` и текст ошибки 12–14 px под полем. Подпись над полем (Inter 14, вес 500). Для чисел `inputMode="numeric"`.

### 6.3. Чекбокс, переключатель, чек-лист
- Чекбокс: скруглённый квадрат 24×24 (радиус 6), обводка `--gray-500`/`--primary`; выбранный — заливка `--primary` и белая галочка. Нажимаемая область 44×44.
- Чек-листы (шаги ДЗ, отметка присутствия) используют тот же чекбокс.
- Переключатель (Switch): включён — `--primary`.

### 6.4. Карточка
Фон `--card`, радиус 12 (`--radius-lg` для крупных), граница 1 px `--border`, `--shadow-card`, внутренний отступ 16. Инфоблоки на сером фоне — карточки на `--muted`.

### 6.5. Бейдж-категория (предмет/формат)
Из слайдов (5.1): текст Montserrat 800 заглавными, цвет `--brand-green-dark`, фон `--green-tint`, радиус 8, высота 28, слева точка-маркер 8 px. ⚠ Точка в интерфейсе **зелёная** (`--brand-green`), не амбер (чтобы не размножать акцент). Пример: «ЕГЭ · ИНФОРМАТИКА» (не более 3 слов).

### 6.6. Статус-бейджи (единый компонент `StatusBadge`)
Высота 24, радиус 8, Montserrat 800 11 px заглавными, слева точка или иконка 12 px. Таблица соответствия **единственная**, другие места её не дублируют.

### 6.7. Чип результата («11/13»)
Адаптация «акцентной цифры» (5.2): Unbounded 700, обводка 2 px и подложка. Варианты:
- **В списках** (карточка ДЗ): обводка и текст `--primary`, подложка `--green-tint`.
- ⚠ **Детальный экран / «последний результат» на отчёте** (один на экран): обводка `--brand-amber` (90%), подложка `rgba(255,155,46,.12)`, цифра `#141414` (контраст) или крупная цифра ≥ 24 px. Отступы обводки симметричны со всех сторон.
Показывает «балл из максимума» и в скобках процент («11 из 13 · 85%»).

### 6.8. Карточка урока
Блоки: время (Unbounded 700, 20 px; конец урока серым), предмет и бейдж категории, участники (для группового — «Группа · 3» без имён у ученика), статус, кнопки ссылок. Ссылки **Телемост** и **Доска** — две кнопки `secondary` с иконками; в карточке «ближайший урок» героя Телемост — `highlight`. Отменённый урок: приглушённый, время зачёркнуто, статус «Отменён».

### 6.9. Карточка ДЗ
Название (H3), бейдж предмета, **дедлайн** («до 14 окт, 17:00»; просроченный — красный текст + бейдж «Просрочено»), статус, чип результата (если проверено). Для ученика: оставшиеся переносы **не показываются в цифрах**, только «дедлайн перенесён» (микро-метка). Нажатие открывает детали.

### 6.10. Загрузчик файлов
Область «Добавить фото» с пунктирной обводкой `--gray-500`, радиус 12; кнопка камеры/галереи. Превью — квадраты 88×88, радиус 8, крестик удаления (44×44 область); прогресс — тонкая полоса `--primary`; ошибка файла — красная подпись под превью («Файл больше 10 МБ»). Счётчик «3 из 10».

### 6.11. Таблицы (десктоп админки)
Граница 1 px `--border`, заголовок Montserrat 700 12 px, зебра: белый / `--gray-100`, высота строки 48. На мобильном таблицы превращаются в карточки.

### 6.12. Нумерованные шаги
Крупная цифра «01», «02» (Unbounded, `--primary`) + короткий текст. Используется в подсказках, онбординге и пошаговых экранах (например, «Как сдать ДЗ»).

### 6.13. Иконки
- **lucide-react**, контурные, толщина линии 1.75–2, скруглённые окончания; цвет: белый на зелёном, `--primary`/`--foreground` на светлом.
- Функциональные иконки (навигация, кнопки) — без ограничений по числу.
- **Тематическая/декоративная иконка (ноутбук, код `{ }`, график, книга) — не более одной на экран/карточку.** Её нет в списках повторяющихся элементов.
- Никаких заливных, объёмных, 3D-иконок.

### 6.14. Диалоги, шторки, тосты
- Шторка (Sheet) снизу на мобильном для форм и действий; Dialog по центру на десктопе, радиус 16, тень `--shadow-overlay`.
- Подтверждение опасных действий: заголовок с последствием («Отменить урок 14 окт, 17:00?»), две кнопки: `outline` «Назад» и `destructive` с глаголом («Отменить урок»).
- Тост (Sonner): снизу на мобильном, сверху справа на десктопе; успех — `--primary` фон, белый текст; ошибка — `--destructive`; длительность 3–4 с.

### 6.15. Графики (Recharts)
- Линия основной серии `--brand-green` (толщина 3), вторая серия `--gray-900`, цель/порог — пунктир `--gray-500`.
- Точка «последнего результата» может быть амбером (это единственный амбер-акцент графика/экрана).
- Сетка `--gray-200`, подписи Inter 12 px `--gray-600`, подсказка — белая карточка с тенью.
- Всегда: подписи осей, пустое состояние, текстовая сводка («Последний результат: 78%»). Смысл не только цветом: точки с маркерами и подписи.
- Шкала Y для оценок ДЗ: 0–100%.

### 6.16. Состояния
| Состояние | Вид |
|---|---|
| Загрузка | Скелетоны `--gray-200` с мягким мерцанием (150–200 мс), контур как у карточки |
| Пусто | Одна контурная иконка 40 px (`--primary`), заголовок (H3), подсказка (14 px), кнопка при необходимости; лёгкий наклон иконки допустим |
| Ошибка | Иконка-предупреждение, понятный текст, кнопка «Повторить» |
| Нет сети | Баннер сверху `--amber-tint` с текстом «Нет соединения. Проверим ещё раз» |
| Нет доступа / не найдено | Нейтральный экран, кнопка «На главную» |
| Идёт отправка | Кнопка в состоянии loading, поля блокируются |
| Успех | Тост |
Анимации: 150–200 мс, ease-out; при `prefers-reduced-motion` отключаются.

## 8. Тон и тексты

### 8.1. Тон (из брендбука)
- Прямо, коротко, без воды. Факты и цифры вместо оценочных слов.
- Честно: без обещаний конкретного балла («доведу до твоего максимума» — можно, «гарантируем 100» — нельзя).
- Не более **одного** восклицательного знака в блоке текста; в интерфейсе по умолчанию без них.
- ⚠ Обращение: **Student App и сообщения бота ученику — на «ты»**. **Admin App и сообщения бота персоналу — нейтрально** (безличные формулировки: «Сохранить», «Ученик создан»). Для возможного будущего родительского доступа — «вы».

**BotFather:** команды на русском в стиле «Открыть приложение», «Расписание на сегодня», «Мои ДЗ», «Войти в браузере», «Отвязать аккаунт».

Для шаблона — дни недели, время, период, предпросмотр ближайших дат. Ошибка пересечения: «В это время уже есть урок».

**9.2.7. Отметка проведения урока.** Список участников; для каждого — выбор присутствия (Был / Не пришёл / Отменено) и чекбокс «Засчитать занятие»; по умолчанию «Был» включает засчитывание. Кнопка `primary` «Завершить урок». Для `owner` показывается цена снимка, менеджер её не видит.

**9.2.8. ДЗ: список, создание, выдача.** Список заданий с индикатором «сдали N из M». Форма создания: тип (Обычное / Пробник), название, описание, файл-материал, **число заданий** (= максимум, 1 задание = 1 балл) либо для пробника — тип экзамена и максимум, привязка к уроку (необязательно), срок (следующее занятие / дата), выбор учеников (мультивыбор и «вся группа»).

**9.2.9. ДЗ: проверка.** Слева (десктоп) / сверху (мобильный): файлы ученика с просмотром фото (масштаб, перелистывание), комментарий ученика. Справа/ниже: поле балла (число, ограничено максимумом, подсказка «из 13»), комментарий, файлы проверки, кнопки: `primary` «Сохранить оценку», `outline` «Вернуть на доработку», действие «Перенести дедлайн на следующее занятие» (показывает, сколько переносов осталось: «Осталось 1 из 2»; после двух — неактивно с пояснением). Для пробника — показать конвертацию («17 баллов = оценка 5» или «тестовый 70»).

**9.2.10. Пробники.** Список результатов с фильтрами по ученику и экзамену; форма ввода: ученик, экзамен (4 типа), дата, первичный балл, максимум (по умолчанию официальный), для ОГЭ математика — баллы за геометрию; результат конвертации показывается сразу, при нестандартном максимуме — «Шкала не применима».

**9.2.11. Финансы и статистика (owner).** Период (неделя / месяц / произвольный), срез (ученик / предмет). Карточки: «Заработано», «Ожидается» (одна из них — амбер-акцент экрана), «Отмены». Таблица по ученикам, график по неделям, кнопка «Экспорт CSV». Менеджеру раздел недоступен.

**9.2.12. Каталог услуг.** Список карточек с переключателем «Опубликовано», перетаскивание для порядка, форма: название, описание, стоимость текстом.

## 10. Доступность (минимум)
- Нажимаемые области не меньше 44×44 px; у иконок-кнопок есть `aria-label`.
- Смысл не только цветом (статус — цвет + текст).
- Контраст по таблице 3.3; выбранные пары перед релизом проверить инструментом.
- Видимый фокус (`--ring`) при навигации с клавиатуры на десктопе.
- Графики сопровождаются текстовой сводкой.
- `prefers-reduced-motion` отключает анимации.
- Минимальный размер основного текста 16 px; масштабирование шрифта системы не ломает вёрстку.

## 11. Чек-лист ревью экрана перед сдачей
- [ ] Не более одного амбер-элемента (кнопка или цифра) в видимой области.
- [ ] Одна главная кнопка (`primary` или `highlight`).
- [ ] Цвета только через токены, шрифты через `font-display`/`font-heading`/`font-body`.
- [ ] Заголовок экрана заглавными, ≤ 2 строк; длинный текст не заглавными.
- [ ] Нет запрещённых слов и штампов, не более одного «!» в блоке.
- [ ] Обращение по правилу (ученику «ты», персоналу нейтрально).
- [ ] Не более одной тематической иконки; нет заливных/3D-иконок.
- [ ] Радиусы из шкалы (8/12/16), нет острых углов и «везде pill».
- [ ] Нет `backdrop-filter` и `filter: drop-shadow` (кроме декоративных элементов героя).
- [ ] Есть состояния: загрузка, пусто, ошибка, отправка.
- [ ] Статусы только через `StatusBadge` по таблице 6.6.
- [ ] Ученик/менеджер не видят цены и финансы.
- [ ] Проверено на 360 px и 1280 px, в светлой и тёмной теме.
