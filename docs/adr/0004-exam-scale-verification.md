# 0004. Шкалы экзаменов 2026 (T0.04)

- **Статус:** Принято; **шкалы подтверждены владельцем 2026-10-06** (T1.05 закрыта решением владельца)
- **Дата:** 2026-10-06
- **Задача:** T0.04 (`docs/PLAN_FROM_SCRATCH.md`)
- **Контекст:** шкалы перевода первичных баллов в тестовые (ЕГЭ) и оценки (ОГЭ) для четырёх экзаменов заданы по данным на 2026 год (`docs/04`, раздел 10).
- **Решение:**
  - Шкалы 2026 года из `docs/04` приняты владельцем как верные; отдельная сверка с ФИПИ/Рособрнадзором не требуется и боевой запуск не блокирует.
  - В коде шкалы — только данные (таблица `grade_scales`), а не константы.
  - Ежегодно шкалы обновляются добавлением строк с новым `valid_year`.
- **Последствия:** пометки «ожидает сверки» из сидов и документации убраны.
