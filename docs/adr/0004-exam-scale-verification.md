# 0004. Шкалы экзаменов 2026 (T0.04)

- **Статус:** Принято; **требует сверки владельцем до боевого запуска**
- **Дата:** 2026-10-06
- **Задача:** T0.04 (`docs/PLAN_FROM_SCRATCH.md`)
- **Контекст:** шкалы перевода первичных баллов в тестовые (ЕГЭ) и оценки (ОГЭ) для четырёх экзаменов (информатика ОГЭ/ЕГЭ, математика ОГЭ/ЕГЭ) заданы по данным на 2026 год (`docs/04`, раздел шкал; `docs/00` §6 «актуальны на 2026 год»). Источник для них — вторичные справочные материалы, не выверенные владельцем.
- **Решение:**
  - Шкалы 2026 года берём из вторичных источников и фиксируем в `docs/04`.
  - **До боевого запуска владелец обязан сверить** шкалы с официальными материалами ФИПИ/демоверсиями текущего года; обновлять их ежегодно.
  - В коде шкалы — только данные (таблица `grade_scales`), а не константы.
- **Последствия:** до сверки владельцем шкалы валидны для разработки и тестов, но помечаются как «ожидают проверки»; перед вводом реальных учеников владелец подтверждает значения.
