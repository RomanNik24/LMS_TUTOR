# 0006. Видимость репозитория (T0.04)

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Задача:** T0.04 (`docs/PLAN_FROM_SCRATCH.md`)
- **Контекст:** репозиторий создан **public** на время разработки (`docs/PLAN_FROM_SCRATCH.md`, строка «Репозиторий Создаёте вы, public на время разработки»; `docs/ops/REPO_SETTINGS.md` §4). При этом `docs/09` §5 формулирует «Репозиторий приватный» как целевое состояние. Нужно зафиксировать правило смены видимости.
- **Решение:**
  - Репозиторий остаётся **public** в течение разработки (до перехода к реальным данным).
  - Перед загрузкой **реальных данных учеников** репозиторий **обязательно переводится в private** (плановая задача T9.01).
  - Это же правило относится к любым загружаемым файлам и секретам: боевые данные — только в private.
- **Последствия:** до T9.01 в public-репозитории не должно быть реальных персональных данных, файлов учеников и секретов; перевод в private — обязательный шаг перед пилотом с реальными учениками.
