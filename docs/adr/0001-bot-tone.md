# 0001. Тон общения бота и интерфейса (T0.04)

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Задача:** T0.04 (`docs/PLAN_FROM_SCRATCH.md`)
- **Контекст:** `docs/05_bot_logic_and_fsm.md` §8 предписывала тон бота «вежливо, коротко, на „вы“». `docs/07_design.md` §8 («Тон и тексты») для заполненного дизайн-документа задаёт другой тон. По правилу приоритета документов (`docs/00` §3, `docs/07` §0) `docs/07` — единственный источник истины по тону. Это расхождение и разрешает данный ADR.
- **Решение:**
  - **Ученику (Student App и сообщения бота ученику) — на «ты».**
  - **Персоналу (Admin App и сообщения бота персоналу) — нейтрально**, безличные формулировки («Сохранить», «Ученик создан»).
  - Тон везде: прямо, коротко, без воды; без обещаний конкретного балла; без родовых окончаний («готов/а»); не более одного восклицательного знака в блоке.
- **Последствия:** все пользовательские тексты (`src/core/texts.py`, `frontend/src/lib/texts.ts`) составляются по `docs/07` §8. Указание «на „вы“» в `docs/05` §8 заменяется ссылкой на `docs/07` §8 (минимальная правка в T0.04). Дальнейшая сверка формулировок — владельцем.
