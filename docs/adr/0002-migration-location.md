# 0002. Расположение миграций Alembic (T0.04)

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Задача:** T0.04 (`docs/PLAN_FROM_SCRATCH.md`)
- **Контекст:** нужно зафиксировать единое расположение миграций и конфигурации Alembic, чтобы задачи T-этапа (T1.02, T3.01, T4.01 и далее) работали единообразно. `docs/03_architecture.md` §3 упоминает `db/migrations/ (Alembic)`, но не закрепляет полный путь и место `alembic.ini`.
- **Решение:**
  - Ревизии Alembic лежат в **`src/db/migrations/`**.
  - Файл конфигурации **`alembic.ini` находится в корне репозитория**.
  - Модели SQLAlchemy — в `src/db/models/`.
- **Последствия:** `alembic.ini` добавляется в корень (справочно к дереву в `docs/03` §3 и в `README`). Точка входа для команд `alembic upgrade head` / `downgrade` — корень репозитория.
