# 0008. Пакеты фронтенда для входа (T1.13)

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Контекст:** задача T1.13 (`docs/PLAN_FROM_SCRATCH.md`): тонкий срез входа во фронтенде. Пакеты входят в утверждённый стек `docs/02` §3.1; версии выбраны как актуальные стабильные и закреплены точно (как в ADR 0007).
- **Решение:**

| Пакет | Версия | Причина |
|---|---|---|
| react-router-dom | 7.18.4 | Роутинг (`docs/02`, `docs/12` §5.4); совместим с React 19. |
| @tanstack/react-query | 5.104.1 | Данные с сервера и кеш (`useMe`, мутации входа), `docs/12` §4.4. |
| @telegram-apps/sdk-react | 3.3.9 | Нативная кнопка «Назад», инициализация Mini App, тема. Используется только в `src/lib/telegram.ts` (ESLint запрещает импорт из других мест). Подключение скрипта `telegram.org/js/telegram-web-app.js` по-прежнему не используется. |

- **Последствия:** у `@telegram-apps/sdk-react` 3.x устаревшие (deprecated) транзитивные пакеты `@telegram-apps/bridge`, `transformers`, `types`; они остаются внутри SDK, наш код их не импортирует. Обновление SDK — отдельным осознанным коммитом с проверкой API кнопки «Назад» и темы.
