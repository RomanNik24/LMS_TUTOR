# 0011. Пакеты фронтенда для UI-каркаса (T2.05)

- **Статус:** Принято
- **Дата:** 2026-10-07
- **Контекст:** задача T2.05: layouts и общие компоненты по `docs/07` §6–§7 (shadcn-подход поверх Radix, Tailwind v4). Пакеты входят в стек `docs/02` §3.1; версии закреплены точно (как в ADR 0007, 0008), `pnpm audit` чист.

| class-variance-authority | 0.7.1  | Варианты кнопок и бейджей.                       |
| lucide-react             | 1.52.0 | Контурные иконки (`docs/07`).                    |
| sonner                   | 2.0.8  | Тосты.                                           |
| @radix-ui/react-dialog   | 1.2.0  | Доступные диалог и шторка.                       |
| @radix-ui/react-tabs     | 1.1.22 | Доступные вкладки.                               |
| @radix-ui/react-slot     | 1.4.0  | `asChild` у кнопки.                              |

- **Последствия:** обновление — отдельным коммитом с прогоном тестов и визуальной проверкой.
