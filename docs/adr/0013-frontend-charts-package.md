# 0013. Пакет графиков фронтенда (T6.05)

- **Статус:** Принято
- **Дата:** 2026-10-08
- **Контекст:** задача T6.05 (docs/PLAN_FROM_SCRATCH.md): графики «средний процент ДЗ», пробники и «Сдано в срок» у ученика и во вкладке «Пробники и прогресс» (docs/07 §6.15, §9.1.6). Библиотека графиков **Recharts** уже названа в стеке (`docs/02_tech_stack.md`, `docs/12_frontend_guide.md`), поэтому отдельного согласования нового стека не требуется; версия закреплена точно (как в ADR 0007, 0008, 0011).
- **Решение:**

| Пакет    | Версия | Причина                                                        |
| -------- | ------ | -------------------------------------------------------------- |
| recharts | 3.10.1 | Линейные графики с осями, подписями и `ResponsiveContainer`.   |

  `pnpm audit` чист. Экраны с графиками (`StudentReportsPage`, `StudentCardPage`) подгружаются лениво, Recharts и его зависимости вынесены в отдельный чанк `vendor-charts` (около 297 кБ, 82 кБ gzip), поэтому ни вход, ни остальные экраны его не грузят.
- **Последствия:** обновление — отдельным коммитом с прогоном тестов и просмотром графиков в светлой и тёмной теме. Цвета линий и осей берутся из токенов (`var(--primary)`, `var(--border)`); у каждого графика есть подписи осей, пустое состояние и текстовая сводка для доступности.
