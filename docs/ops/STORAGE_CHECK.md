# Проверка хранилища (T4.04)

Дата: 2026-10-08. MinIO из `docker-compose.yml` (профиль `full`), бакет `lms-files`. Секретов, ключей и подписанных ссылок в документе нет.

| № | Проверка | Результат |
|---|---|---|
| 1 | Анонимное чтение объекта `GET http://127.0.0.1:9000/lms-files/<ключ>` без подписи | `403` |
| 2 | Анонимный листинг бакета | `403` |
| 3 | Загрузка через API (`POST /student/homework/{id}/files`: JPEG, PNG, HEIC, PDF) | `201`, ключи `homework/{assignment_id}/{uuid}.{ext}` (PNG и HEIC сохранены как JPEG) |
| 4 | Подписанная ссылка `GET /files/{id}/url` | `200`, `expires_in = 600`, в ссылке `X-Amz-Expires=600`; открывается с ПК (`200 image/jpeg`) |
| 5 | Ссылка на несуществующий файл | `404` |
| 6 | Истечение подписанной ссылки по TTL | **не проверялось в этом прогоне** (нужна ссылка с коротким TTL и ожидание); срок в ссылке подтверждён пунктом 4 |
