## Что проверяет автотест (все экраны сразу)

| Пункт чек-листа | Правило теста |
|---|---|
| 1. Один амбер | в файле экрана не больше одного `bg-highlight` / `variant="highlight"` |
| 3. Токены, шрифты | нет hex, `rgb()`, `hsl()`; нет цветов палитры Tailwind (`gray-*`, `red-*`, `white` и т. д.); нет `font-sans/serif/mono` |
| 5. Слова, «!» | в `texts.ts` нет запрещённых слов и штампов (`docs/07` §8.1), не больше одного «!» в строке |
| 7. Иконки | в текстах интерфейса нет эмодзи (только line-art иконки lucide) |
| 8. Радиусы | нет `rounded-xl/2xl/3xl/[…]`: только 8/12/16 и `full` для маркеров |
| 9. Фильтры | нет `backdrop-*`, `drop-shadow`, `blur` |

## Что исправлено

| Находка | Исправление |
|---|---|
| `text-gray-600` и `bg-gray-200` — цвета бренда без тёмного варианта: в тёмной теме подписи таб-бара, «Ещё», заголовка блока на экране расписания ученика и скелетон теряли контраст | заменены на `text-muted-foreground` и `bg-muted` (токены с тёмной темой) |
| «Отчёты» ученика: свой `<h1>` без заглавных вместо общего заголовка | использует `PageHeader` |
| «Проверка ДЗ»: ручной перенос срока — вторая `primary`-кнопка рядом с «Оценить» | кнопка стала `outline` |
